# 风格定调说明 —— 请在展开后续章节前确认

> 随附文件：第 0 章定调稿 + 第 3 章定调稿
> 本说明列出风格层面的关键决策点，每条都已给出"当前稿的做法"，你只需要说"OK"或指出要改的地方。全部确认后我按此风格批量展开剩余 12 章。

## 一、待确认的 8 个风格决策点

### 1. 叙事人称：第二人称"你" 【第 0 章 §0.1、第 3 章 §3.1】

**当前做法**：通篇用"你"直接对话读者（"请诚实地回答一个问题：你能说出……吗？"），不开"我们"（"让我们来看看"）。

**理由**：本书目标是戳中 cargo-cult 痛点，第二人称才有 confrontational 张力；"我们"会让诊断变成集体免责。

### 2. 场景引入的写法：微小说式开头 【第 0 章"上周五的那条命令"、第 3 章"一次 0.3 秒的犹豫"】

**当前做法**：每章从一个极具体的身体化瞬间切入（手指停在回车键上 0.3 秒），先唤起体验再进概念，长度 200–400 字。

**备选**：也可以改为"问题清单式"开头（直接罗列 5 个典型困惑），更快但少了代入感。

### 3. 比喻系统的密度与一致性 【项链/珠子/标签 vs 货物崇拜】

**当前做法**：全书统一用**项链-珠子-标签**比喻体系贯穿分支概念（分支=标签、提交=珠子、历史=项链）；第 0 章用**货物崇拜**比喻开篇（一次性用完即弃，不复用进其他章）。每章至多 1 个主比喻 + 1 个辅助比喻。

**注意点**：如果你觉得项链比喻太文艺/太密，可退回中性说法（"提交图/节点/指针"），但会损失一部分可读性。

### 4. AI 指令箱的呈现方式 【两章已略有不同的两种格式】

**当前做法**：
- 第 0 章结尾：一个"陪练模式"指令块（AI 当学习伙伴，不操作 Git）
- 第 3 章：分级指令箱（🟢导航/🟢开分支/🟡需盯着/陪练/实战演练），带红黄绿颜色标注

**待确认**：第 3 章的"分级 + 颜色"格式是否作为全书标准？还是简化为统一的单一指令块？（我推荐分级版，因为安全颜色体系是全书卖点之一，从第 3 章开始预热）

### 5. "执行后的世界"透视表 【第 3 章 §3.6】

**当前做法**：用一张三列表（你说的话 → AI 执行的命令 → .git 里的真实变化）揭示"指令背后的物理事实"。

**待确认**：这个栏目是否保留为每章固定栏目？我的看法：概念部分章节保留，场景部分章节用，是全书"祛魅"手法的关键装置。

### 6. 误解拆解的数量与写法 【每章末"三大典型误解"】

**当前做法**：每章固定 3 条，格式为"误解原文（带引号的内心独白）→ 逐条驳斥 + 给出正确心理模型"。语气允许略微毒舌（"年限不替换概念，只加深肌肉记忆"）。

**待确认**：毒舌程度是否合适？可以调节：A. 保持当前力度 B. 收敛到温和客观 C. 更狠。

### 7. 章末结构的固定栏目顺序 【两章当前的结尾】

**当前顺序**：正文 → 命令侧栏 → 本章小地图（ASCII 图）→ 三大误解 → 下一章预告 → AI 指令箱。

**待确认**：AI 指令箱放最后（作为"行动召唤"收尾）还是放小地图之前（作为正文一部分）？当前两章略有不同（第 0 章在最后，第 3 章也在最后但多了一个实战演练块）。我建议全书统一为：正文 → 命令侧栏 → 小地图 → 误解拆解 → 下一章预告 → AI 指令箱收尾。

### 8. 图的处理方式 【ASCII 示意图】

**当前做法**：正图用文字描述 + ASCII 线框图占位（如图 3-1 的项链图），正式出版时替换为统一风格绘制的矢量图。

**待确认**：这个阶段的稿件是否接受 ASCII 占位？还是需要我先用绘图工具（Mermaid/SVG）出正式图？

## 二、两章的分工与代表性说明

- **第 0 章**代表"理念章"写法：重论证、重情绪、建立全书世界观（cargo-cult 诊断 → 地图宣言 → AI 分工公式）。
- **第 3 章**代表"概念章"写法：重祛魅、重视觉、一个核心反直觉点打穿（分支=一行文本），配完整栏目全家桶（场景/概念/HEAD/判断规则/指令箱/透视表/侧栏/小地图/误解）。

后续第 2 部分的"场景章"（第 6–11 章）将以第 3 章为模板再加"症状→判断→指令"的决策结构。两章覆盖了全书最难写的两种文体，风格一旦锁定即可平移。

## 三、确认后的展开节奏

1. **概念批**（第 1、2、4、5 章）：仓库/提交/远程/历史
2. **场景批**（第 6–11 章）：提交/分支策略/Worktree/冲突/恢复/协作
3. **压轴批**（第 12–14 章 + 附录）：安全红线/进阶/结语 + 命令速查表 + 提示词全集
