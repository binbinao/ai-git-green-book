# 出版级 PDF 构建管线

`manuscript/*.md` → 出版级 PDF（`output/git-concept-map-full.pdf`），单命令可复现：

```bash
build/build.sh
```

**退出码即结论**：第 6 步是复验闸门（`qa_report.py` 23 项 + `qa_fonts.py` 字体嵌入），
任一不过则以非 0 退出。也就是说 `build.sh` 静默通过 = 23 项与字体嵌入全部达标。

## 依赖

| 工具 | 用途 | 安装 |
|---|---|---|
| typst ≥ 0.15 | 排版编译 | `brew install typst` |
| pandoc ≥ 3 | Markdown → Typst 转换 | `brew install pandoc` |
| Sarasa Fixed SC | 代码/ASCII 图 2:1 中英等宽字体 | `brew install --cask font-sarasa-gothic` |
| 宋体/黑体/楷体 (Songti/Heiti/Kaiti SC) | 正文/标题/引文 | macOS 系统自带 |
| PingFang SC | 节标题黑体 | macOS 系统自带 |
| Alibaba PuHuiTi 3.0 | 章扉/封面展示字（缺失则回退 PingFang SC） | 可选 |
| pymupdf | **复验与收尾必需**（`qa_report.py` / `qa_fonts.py` / `finalize.py`） | `build/.venv` 内已隔离 |

## 管线步骤（build.sh，共 7 步）

1. **assemble.py** — 拼 19 个书稿文件为 `build/book.md`，剥离每章重复的章位引言块引与章首 `---` 脚手架（保留 h1 章题）。
2. **pandoc** — `-f markdown-smart -t typst --wrap=none`：
   - `markdown-smart` 关掉智能引号转换（防止中文直引号被误弯成错误方向的弯引号，P0-1）；
   - `--wrap=none` 是关键：pandoc 默认把段落硬折到 ~72 列，折行在 Typst 里等价于插入一个空格，于是「——」「；」这类禁则字符前面多出一个可断行点，折行后就落到行首（P2-17 的行首破折号正是这么来的）。
3. **postprocess.py** — 后处理：
   - `[@小李]` 式对话人名还原（pandoc 误判为 citation）；剥变体选择符 U+FE0F / 零宽连接符 U+200D；
   - **行首/行末禁则**：给「——」绑 WORD JOINER（U+2060），并把「全角标点紧邻行内代码盒」的接缝一并绑住（全书仅 3 处真实违规，见下「文本层洁净」）；
   - 表格列宽改写：pandoc 的等宽百分比列 `(33.33%,…)` → 内容加权 `(1.15fr, 1.15fr, 1.7fr)` 等；
   - 保留 `table.header(...)`（P1-11 表头）并剥掉表格 figure 壳（figure 不可跨页，会溢出页尾与页码重叠）；
   - 解析章号/标题供 `book.typ` 的章扉函数用；组装前置页（封面/扉页/版权页/目录）+ 打开 in-body state；版本号与日期从 `book.typ` 的 `meta` 读取（单一版本源，P1-14）。
4. **typst compile** — `build/book-final.typ` → `output/git-concept-map-full.pdf`。
5. **finalize.py** — 配帖补页（P1-15：补空白页至 4 的倍数）+ 把实测页数/体积/日期写回本文件「版本」节（P1-14）。
6. **复验闸门** — `qa_report.py`（23 项，几何取证）+ `qa_fonts.py`（字体嵌入）；任一不过 → 非 0 退出。
7. **完成** — 打印 PDF 体积；若有 FAIL 行则附警告。

## 插图管线

图题与图号**跟着稿件走**：源稿用标准 Markdown `![图 <章>-<序>：<中文说明>](figures/<slug>.png)`，
pandoc 转成 `#figure(image(...), caption: [...])`。没有 `figures.yaml` 之类的映射表
—— 图题就是正文的一部分，改图题 = 改稿件。

| 脚本 | 用途 |
|---|---|
| `render_figure.py` | archify spec（JSON）→ 端到端出 PNG：render HTML → Chrome 4× 浅色主题截图 → 去点阵底纹 |
| `render_figure2.py` | 同上 v2，修正 v1 固定 `--window-size=1100,620` 导致的「16:9 截断」 |
| `scan_figures.py` | 扫描书稿所有 ASCII 图，输出 JSON 列表（位置/内容/行数/绘图字符数），供写 spec 参考 |
| `show_fence.py` | 读指定文件第 idx 个围栏（调试用） |

素材与 spec 放在 `build/figures/`（14 张 PNG + 同名 JSON spec），细节见 `build/figures/README.md`。

## 出版级版式规格（book.typ）

- **开本** 172×248mm；四边留白 26mm（上 27mm / 下 25mm），版心 120×196mm（模板按 120×195mm 保守取用，供图块适配）
- **正文** 宋体 SC 10.5pt，行距 1.75em，首行缩进 2em，两端对齐
- **中英间隙** `cjk-latin-spacing: none` —— 源稿的中西文间隙是作者**逐处手打**的（实测 8488 处「中_西」+ 8366 处「西_中」，无一处漏打），引擎再自动插一次只会在「拉丁 → 全角收尾标点」这类错位边界上塞进多余间隙（P1-8 的表象）。关掉即与手打结果一致。
- **标题** 黑体层级：h1=章扉 / h2=节 14.5pt / h3=小节 12pt / h4=强调 10.5pt
- **章扉** 独占一页、无书眉无页码；巨型章号（展示字 88pt）+ 章名 25pt + 琥珀色短线；**统一落奇数页（右页）**，为凑奇数页插入的空白页不带书眉与页码（P2-16）
- **代码块** Sarasa Fixed SC；**按版心自适应缩字号**（8.5pt 起，下限 7pt），保证绝不横向折行；ASCII 箱线图额外禁跨页（P0-5、P1-13）
- **行内代码** 9.0pt（正文）/ 6.2pt（表内），按空格切分成不可断小盒，`git count-objects -vH` 这类开关不会被劈开（P1-13）
- **块引** 楷体 + 左侧 3pt 深青竖线
- **表格** 9pt；深青表头白字 + 斑马纹；跨页断行并重复表头
- **安全标记** 红黄绿 🟢🟡🔴 换成**纯矢量圆点**（AppleColorEmoji 是 Type3、无 FontFile，印刷 preflight 会判「未嵌入」）；其余装饰 emoji 一并收敛为可嵌入字体里的等价符号（P1-7）
- **图题** `图 <章>-<序>：<中文说明>` 置于图下方，9pt 灰字；用 `it.body` 取 caption 正文，**丢掉** Typst 的自动编号（P0-6）
- **书眉** 正文页：偶数页=书名、奇数页=当前章名，眉线居中；前置页与章扉无书眉
- **页码** 切口侧（偶数页左、奇数页右），前置页无页码
- **目录** 章+节两级，点线页码；PDF 书签 467 条

## QA 工具

| 脚本 | 检查内容 |
|---|---|
| `qa_report.py` | **23 项**几何取证复验（对应 REVIEW-v3 的 19 项发现）：逐页 span 坐标、字体判别、绘制矩形、按 baseline 归并行 —— 输出 PASS/FAIL 明细与汇总，退出码 0/1 |
| `qa_fonts.py` | 字体嵌入体检：列出 PDF 每款字体及其 FontFile 嵌入状态（当前 14 款，未嵌入 0） |

`qa_report.py` 文件头记着 6 条「踩过的坑」（字体判别法、行归并、悬挂标点合法、
探针要与发现同名、**修复手段本身也要设闸门**、**判据要落在最终产物上**），改检查项前先读。

### 文本层洁净（P2-17 的代价控制）

行首/行末禁则的保护手段本身会留下痕迹，这里记一笔：

- Typst 依 UAX#14 断行（LB13 不在收尾标点前断、LB14 不在开括号后断），**纯中文语境
  引擎自己就排得对**；
- UAX#14 覆盖不到的只有两处：①「——」的断行机会；②**行内代码盒的接缝**
  （行内代码是 `raw` 生成的原子盒，盒边界上的断行不受标点规则约束）；
- 所以早期「见标点就插 U+2060」的写法会把约 **6000 个不可见字符**灌进文本层，
  代价是 PDF 里「图 0-1：」「常见混淆：」「（Repository）」全部**搜不到、复制带隐含字符**；
- 收窄判据后只剩 **1610 处**（其中 1445 处是必需的破折号绑定），文本层 U+2060 实测
  1311 个、含它的书签 17 条，上述探针全部可直接检索 —— 并由 `qa_report.py` 的
  「文本层洁净」一条长期看守。
